# Support

## Getting Help

Thank you for using the Data Cap WP Plugin! If you need help, here are the best resources:

### Documentation

- **[README](README.md)** - Start here for setup instructions and basic usage
- **GitHub Issues** - Check [existing issues](https://github.com/tim-dickey/Data-Cap-WP-plugin/issues) to see if your question has been answered

### GitHub Issues

Please use GitHub Issues to:
- **Report bugs**: Unexpected behavior, errors, or broken functionality
- **Request features**: Suggest improvements or new capabilities
- **Ask specific questions**: About the plugin's functionality or configuration

Use the provided issue templates to ensure we have all the information needed to help you.

## What NOT to Use Issues For

- **General WordPress questions**: Use [WordPress.org Support Forums](https://wordpress.org/support/forums/) instead
- **Hosting/server issues**: Contact your hosting provider
- **Theme compatibility**: Check with your theme developer
- **WordPress core problems**: Report to [WordPress.org](https://wordpress.org/)
- **Spam/advertising**: These will be closed immediately

## Response Times

- **Critical bugs**: We aim to respond within 24-48 hours
- **Features & questions**: We typically respond within 1-2 weeks
- **Documentation issues**: We typically respond within 1 week

Please note that this is a community project maintained by volunteers. Response times may vary based on availability.

## Before Opening an Issue

Please check:
1. The [README](README.md) and documentation
2. [Existing issues](https://github.com/tim-dickey/Data-Cap-WP-plugin/issues?q=is%3Aissue) for similar problems
3. That you're using the latest version of the plugin
4. That WordPress and PHP are up to date

## Issue Details

When opening an issue, please include:
- WordPress version
- PHP version
- Plugin version
- Steps to reproduce (for bugs)
- Expected vs. actual behavior

The more details you provide, the faster we can help!
